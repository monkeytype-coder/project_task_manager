**"Навигатор Задач"**
Система состоит из трех компонентов:
1. Telegram-бот (`pyTelegramBotAPI`) — мобильный интерфейс. Реализован с использованием состояний (user states) и интерактивных меню (`InlineKeyboardMarkup`).
2. Десктопное приложение  — расширенное управление. Построено на PyQt6 (архитектура Model-View). Данные автообновляются по таймеру.
3. База данных (SQLite) — единое хранилище. Спроектирована схема из 4 таблиц (`users`, `teams`, `team_members`, `tasks`) с внешними ключами.

Пользователь взаимодействует через Telegram-бота (быстрое добавление/изменение задач) или десктопное приложение (детальный просмотр и администрирование). Оба интерфейса синхронизируются через общую БД SQLite
